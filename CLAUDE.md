# apostrophe

Back office for small businesses that sell flower by the gram; several businesses in one
installation, and they never mix. Read `CONTEXT.md` before touching anything: its
vocabulary is mandatory in code, tests and issues. `CODING_STANDARDS.md` section 9
(business isolation and privacy) outranks everything else.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`GonzaloZevallos/apostrophe`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary. `agentic` and `needs-human` are reserved for the agentic system, not triage. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the root. See `docs/agents/domain.md`.
