# Campos personalizados: approved drawings (2026-11-05)

The owner chose "Una lista y una hoja por campo" from 5 proposals validated by an independent UX Lead and UI Lead, and
named the concept **"Campos personalizados"**. These drawings are the contract for #394 and #395.

- **The list:** a leaf's custom fields are a calm list. Each row shows a type icon, the name, a summary
  ("Lista · Obligatorio · En el catálogo") and "Usado en N productos". Each field is edited in its own sheet.
  "Así se ve en el producto" previews the form.
- **The owner's decisions are in DECISIONS.md:**
  - no inheritance, with "Copiar campos personalizados de otra categoría" and "Aplicar a las hermanas";
  - the number unit comes from the 7 product units;
  - a list value in use is archived, and a rename updates every product;
  - making a field required warns how many products lack it, without blocking sales.
- **Copy is neutral Spanish:** tú in messages, the infinitive on buttons. The breadcrumb goes up; there are no
  back-arrow rows.
- **Files:**
  - `fuente/telefono/`: 7 screens, each with an `Oscuro` twin;
  - `fuente/compu/`: 2 screens, each with a `CompuOscuro` twin.
